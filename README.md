# CampusHelp — University Student Service Request Portal

**GitHub-Based Project Management Assignment**  
**Work mode:** Individual adaptation, subject to instructor approval.

CampusHelp is a proposed portal where students submit service requests, select category and priority, receive a unique request ID and monitor progress. Administrators assign requests, update statuses and view an open/ongoing/completed dashboard.

## Scope
- Student request submission
- Request categories and priority levels
- Unique request ID and tracking
- Administrator assignment and status updates
- Dashboard for open, ongoing and completed requests

**Out of scope:** production authentication/hosting, live email/SMS and live university-system integration.
