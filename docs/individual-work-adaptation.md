# Individual Work Adaptation

The original course handout specifies exactly three students, at least four tasks per student, one contributed Pull Request per student, peer review, and three progress updates.

This repository is prepared as an individual adaptation because the instructor has permitted one student to complete the assignment. The individual student performs project-manager, analyst/designer and quality/risk-coordinator responsibilities.

No fictitious collaborators, peer reviews or team contributions are claimed. The student should confirm with the instructor how team-only requirements are assessed for an individual submission. Actual work and evidence must be recorded truthfully.
