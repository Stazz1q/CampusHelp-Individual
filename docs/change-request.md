# Change Request CR01 — Email Acknowledgement

## Request
University Administration asks for an automatic email acknowledgement whenever a student submits a service request.

## Scope analysis
Live email delivery is outside the original prototype scope. A simulated confirmation state is inside the demonstration scope.

## Impact
- Provisional additional effort: 3 hours (per assignment brief).
- Estimated additional cost: 3 × 50,000 UZS = 150,000 UZS.
- Schedule impact: could delay testing and final verification.
- Risks: provider configuration, privacy, delivery failures and additional test effort.

## Recommendation: DEFER
Defer live email integration and retain a visible simulated confirmation in the prototype. This protects the 10-day baseline and avoids external service dependencies. Reconsider for a future release.
